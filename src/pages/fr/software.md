| Paquet | Description |
|---|---|
| [jmstate](https://github.com/felixlaplante0/jmstate) | Paquet Python pour les modèles conjoints multi-états. Il fournit des méthodes d’estimation et de prédiction qui relient des marqueurs longitudinaux à des processus de survie multi-états. |
| [pitcp](https://github.com/felixlaplante0/pitcp) | Paquet Python de prédiction conforme avec correction par transformation intégrale de probabilité (PIT). Il transforme un score de non-conformité initial à l’aide d’une fonction de répartition conditionnelle estimée pour obtenir une couverture conditionnelle asymptotiquement exacte. |
| [otica](https://github.com/felixlaplante0/otica) | Paquet Python pour l’analyse en composantes indépendantes sans fonction de contraste, fondée sur le carré de la distance de Wasserstein d’ordre 2 à la loi gaussienne standard. |
| [otlingam](https://github.com/felixlaplante0/otlingam) | Paquet Python pour la découverte causale dans les modèles linéaires non gaussiens. Il mesure l’écart à la gaussianité à l’aide de la distance de Wasserstein. |
| [uniformbands](https://github.com/felixlaplante0/uniformbands) | Paquet Python pour construire des bandes de confiance asymptotiques uniformes en temps pour les fonctions de survie, avec une garantie de couverture à haute probabilité. |
| [sbcluster](https://github.com/felixlaplante0/sbcluster) | Implémentation en Python de Spectral Bridges, un algorithme de classification topologique conçu pour traiter de grands jeux de données. Il partitionne les données en cellules de Voronoï, puis repère les frontières entre groupes et les zones de faible densité à l’aide de méthodes spectrales invariantes par changement d’échelle. |
| [fastkmeanspp](https://github.com/felixlaplante0/fastkmeanspp) | Implémentation C++ pour Python de l’initialisation k-means++. Elle s’appuie sur BLAS pour accélérer le tirage des centres à partir des distances, avec des gains pouvant atteindre un facteur 10 par rapport à scikit-learn. |
| [mimisbm](https://github.com/felixlaplante0/mimisbm) | Portage vectorisé en Python d’un paquet R qui implémente un mélange de modèles à blocs stochastiques multicouches. Le paquet d’origine est disponible sur le [CRAN](https://cran.r-project.org/web/packages/mimiSBM). |
